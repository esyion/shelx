## 4. 视图 C:文件(SFTP 双栏放大到主工作区)

## 7. FinalShell 布局对照

| 区域 | FinalShell | shelx 设计 |
|------|-----------|------------|
| 左侧栏 | 连接树 | 连接树 + 搜索框 + 快速连接按钮(一致),可折叠/拖宽 |
| 顶部 | 连接标签 | 标签 + 在线状态圆点 + 全局快捷键(增强) |
| 中部 | 终端 | 终端(默认)/ 监控 / 文件 三视图切换,Alt+1/2/3(增强) |
| 底部 | 监控面板常驻 + 文件管理页签 | SFTP 双栏 / 传输中心 互斥页签,Ctrl+J 折叠;监控升级为完整视图 + P1 终端侧迷你条 |
| 弹窗 | 认证类较少 | 指纹确认 / 键盘交互 / 冲突 / chmod / 删除确认(安全增强) |
| 整体 | Java Swing,偏亮 | 深色为主,Tailwind + shadcn 语义令牌 |
